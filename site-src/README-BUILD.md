# MiKia website source (saved copy)

These are the files that generate the website in `mikia/` (the code that is deployed). They were kept only in a temporary workspace, so this is the saved copy.

- `build.py` writes the website (it still points at the original workspace paths and needs the image sets from the original `3d` folder, so it will not run from this folder as it is).
- `source-home.html` is the first design the build starts from.
- The generated website, images and API are the real deliverable in `mikia/`; keep editing those until this build is made self-contained.

Making this build run from a clean checkout is stage 1 of the admin project.
