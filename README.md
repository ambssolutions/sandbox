# Jot Punia — personal real estate site

Single-page site for **Jot Punia**, Residential Sales at Barfoot & Thompson (South Auckland).

- `index.html` — the whole site (no build step, vanilla JS)
- `assets/img/` — imagery (illustrative stock photos from Unsplash)
- Add Jot's portrait at `assets/img/jot.webp` (~1000×1250) and it replaces the JP monogram automatically.

Preview locally: `python3 -m http.server`, then open http://localhost:8000.

The appraisal form has no backend: submitting it opens the visitor's email app with a pre-filled message to Jot.

Before launch, confirm the phone number, email address and follower count with Jot.
